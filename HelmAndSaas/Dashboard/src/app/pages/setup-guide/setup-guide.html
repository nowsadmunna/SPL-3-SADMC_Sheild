Connect a Cluster

Install the SADMC Shield agent into your Kubernetes cluster with a single Helm command.

Prerequisites

  • A running Kubernetes cluster and kubectl configured against it
  • helm (v3+) installed locally
  • Network reachability from the cluster's pods to the SaaS address you enter in step 2
  • Your application services expose a Prometheus-format /metrics endpoint with request_duration_seconds (with a status_code label) and process_*. A service without it gets no verdict; the agent logs this once.
  • Permission to run one privileged cAdvisor pod per node (the agent chart deploys it), or an existing cAdvisor whose URL you can give in step 2

4 Verify

  • kubectl get pods -n sadmc shows the agent (and the cAdvisor pod) Running.
  • kubectl logs -n sadmc deploy/sadmc-agent -f shows warming up for about 75 seconds (the agent needs a one-minute window of counters), then Successfully collected metrics for N services every 15 seconds.
  • Your cluster appears in the selector at the top of this dashboard; Overview shows each service as NORMAL until a problem is detected.
  • A service that is listed but has no /metrics endpoint is skipped, with one warning in the agent log.
  • To remove everything: helm uninstall sadmc-agent -n sadmc.
